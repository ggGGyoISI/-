# Бот для постов в Telegram-канал

Бот сам находит новое каждый час: читает указанные тобой **Telegram-каналы** и ищет **свежие новости в интернете**. Найденное он **переписывает в стиле твоего канала**, **рисует картинку** и **публикует** пост или присылает тебе черновик на проверку.

**Работает бесплатно:**
- поиск в интернете идёт через DuckDuckGo, ключ не нужен;
- чужие каналы бот читает через их веб-версию `t.me/s/канал`, без аккаунта и без ключей;
- тексты пишет бесплатная нейросеть: Google Gemini, Groq, OpenRouter (`:free`) или локальная Ollama;
- картинки рисует нейросеть FLUX.2 через Cloudflare Workers AI (бесплатно ~95 картинок в день) или берутся настоящие фото со стока Pexels. Запасной вариант без регистрации — Pollinations.ai. Если ничего не ответило, бот сам рисует обложку с заголовком.

## Возможности

| Что | Как |
|---|---|
| Следить за каналами | `/watch @канал1 https://t.me/канал2` или просто прислать ссылки |
| Темы для поиска новостей | `/topics ИИ; нейросети; стартапы` |
| Включить автопилот | `/auto on`, выключить — `/auto off` |
| Режим автопилота | `/auto drafts` — присылать черновики мне, `/auto publish` — сразу в канал |
| Постов за проход | `/auto 3` |
| Проверить сейчас | `/check` |
| Написать пост вручную | прислать тему текстом или `/post тема` |
| Переписать чужой пост | переслать его боту и нажать «✍️ Переписать в пост» |
| Научить стилю | переслать посты своего канала, нажать «🎨 Пример моего стиля»; `/style описание` |
| Картинки | `/images on/off`; под черновиком кнопки «🎨 Новая картинка», «📷 Фото со стока», «🚫 Без картинки» |
| Идеи | `/ideas тематика` |
| Публикация | кнопки «✅ Опубликовать», «🕒 Запланировать»; `/queue` — очередь |

### Как работает автопилот

Каждые `AUTO_INTERVAL_MIN` минут (по умолчанию 60) бот:
1. Открывает веб-версии отслеживаемых каналов и берёт посты, вышедшие после прошлой проверки. Реклама (`erid`, `#реклама`) и посты без текста пропускаются.
2. Ищет новости по твоим темам за последние сутки. Новости, которые он уже видел, не берутся.
3. Просит нейросеть выбрать самое интересное (до `/auto N` штук). Повторы недавних постов отсеиваются, посты из каналов важнее новостей.
4. Переписывает выбранное своими словами в стиле твоего канала и дополняет фактами из поиска.
5. Рисует картинку.
6. Присылает черновик с кнопками или сразу публикует в канал (`/auto publish`).

После добавления канала бот не трогает старые посты, а ждёт новые.

## Запуск

1. **Создай бота.** Напиши [@BotFather](https://t.me/BotFather), выполни `/newbot` и скопируй токен.
2. **Получи бесплатный ключ нейросети** на https://aistudio.google.com/apikey (Gemini).
3. **Узнай свой Telegram ID** у [@userinfobot](https://t.me/userinfobot).
4. **Добавь бота в администраторы своего канала** с правом «Публикация сообщений».
5. Установи и запусти (нужен Python 3.10+):

```bash
cd telegram_post_bot
python -m venv .venv
# Windows: .venv\Scripts\activate    Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env      # впиши BOT_TOKEN, LLM_API_KEY, ADMIN_IDS, CHANNEL
python bot.py
```

6. В боте:
   - перешли 5–15 постов своего канала и нажми «🎨 Пример моего стиля» (дальше посты из этого канала он запомнит сам);
   - `/watch @канал1 @канал2` — за кем следить;
   - `/topics твоя тематика` — что искать в новостях;
   - `/auto on` — включить автопилот, `/check` — проверить сразу.

## Бесплатные нейросети для текста

Смена провайдера — три строки в `.env`:

```env
# Groq — https://console.groq.com/keys
LLM_BASE_URL=https://api.groq.com/openai/v1
LLM_MODEL=llama-3.3-70b-versatile

# OpenRouter — https://openrouter.ai/keys (модели с суффиксом :free)
LLM_BASE_URL=https://openrouter.ai/api/v1
LLM_MODEL=<модель>:free

# Ollama — полностью локально
LLM_BASE_URL=http://localhost:11434/v1
LLM_API_KEY=ollama
LLM_MODEL=qwen2.5:14b
```

Сколько запросов тратится:
- на один пост — 1–2 запроса к нейросети;
- на проход автопилота — ещё 1 запрос на выбор лучшего.

При настройках по умолчанию (раз в час, до 2 постов) это около 70 запросов в сутки, то есть в пределах бесплатных лимитов.

## Картинки

Какие сервисы подходят для обложек (все бесплатные):

| Сервис | Качество | Бесплатно | Что нужно |
|---|---|---|---|
| **Cloudflare + FLUX.2 [klein]** (рекомендую) | отличное, свежая модель 2026 года | ~95 картинок в день | бесплатный аккаунт Cloudflare, без карты |
| Cloudflare + Leonardo Lucid Origin | лучшее | ~3 картинки в день | то же |
| **Pexels** — настоящие фото | реальные фотографии | 200 запросов в час | бесплатный ключ |
| Pollinations.ai | среднее, бывает медленно | ~1 картинка в 15 секунд | ничего |
| Обложка с заголовком | простая, без нейросети | без ограничений | ничего |

**Как подключить Cloudflare (5 минут):**
1. Зарегистрируйся на https://dash.cloudflare.com.
2. Скопируй **Account ID** со страницы аккаунта.
3. Создай токен: My Profile → API Tokens → Create Token → шаблон «Workers AI».
4. Впиши `CF_ACCOUNT_ID` и `CF_API_TOKEN` в `.env`.

При `IMAGE_PROVIDER=auto` (по умолчанию) бот сам начнёт рисовать через Cloudflare. Если дневной лимит закончится, он переключится на Pollinations, а при его сбое нарисует обложку.

**Фото со стока.** Получи ключ на https://www.pexels.com/api/ и впиши в `PEXELS_API_KEY`. Под черновиком появится кнопка «📷 Фото со стока». Чтобы реальные фото подбирались сразу, поставь `IMAGE_PROVIDER=pexels,cloudflare`. Ключевые слова для поиска придумывает нейросеть вместе с постом.

**Заголовок на картинке.** `IMAGE_TITLE=on` пишет заголовок поста внизу картинки на тёмной подложке, как у новостных каналов.

Описание картинки и ключевые слова для фотостока нейросеть пишет в том же запросе, что и пост, поэтому лишних запросов нет. Все картинки приводятся к формату 16:9 (1280×720).

Telegram разрешает подпись к фото длиной до 1024 символов. Пост короче этого выходит одним сообщением (фото с подписью). Длинный пост уходит двумя сообщениями: сначала картинка, потом текст. Чтобы посты всегда выходили одним сообщением, поставь `MAX_POST_CHARS=1000`.

## Где запустить бесплатно, чтобы работал 24/7

- Свой компьютер или старый ноутбук: `python bot.py`.
- Бесплатная виртуальная машина, например Oracle Cloud Always Free или Google Cloud e2-micro. Запусти через `screen`/`tmux` или systemd.
- Любой хостинг, где можно запустить Python-процесс. Веб-сервер не нужен.

Автопилот и отложенные посты работают, только пока бот запущен. Данные хранятся в `data/state.json`, картинки — в `data/images/`; неиспользуемые картинки удаляются автоматически.

## Файлы

- `bot.py` — команды, кнопки, отложенные публикации;
- `autopilot.py` — ежечасный поиск нового и автопостинг;
- `tgchannels.py` — чтение публичных Telegram-каналов;
- `search.py` — поиск DuckDuckGo и чтение страниц;
- `writer.py` — промпты и генерация текста;
- `images.py` — картинки (Cloudflare FLUX.2 / Pexels / Pollinations / обложка, заголовок поверх);
- `services.py` — создание черновиков, отправка и публикация;
- `formatting.py` — очистка HTML под требования Telegram;
- `storage.py` — хранение в JSON;
- `config.py` — настройки из `.env`.

## Ограничения

- Следить можно только за **публичными** каналами (с @username). Бот видит последние ~20 постов канала, поэтому при проверке раз в час не пропустит новое, если канал выпускает меньше 20 постов в час.
- Telegram не даёт ботам читать историю канала, поэтому стиль задаётся пересылкой постов.
- Бот пересказывает чужие посты своими словами. Ответственность за использование чужого контента — на владельце канала; при необходимости указывай источник (например, через `/style`: «в конце ставь ссылку на источник»).
- Бесплатные сервисы (DuckDuckGo, Cloudflare, Pollinations, бесплатные тарифы нейросетей) иногда ограничивают частые запросы. Бот это переживает: пропускает проход или переходит к следующему сервису картинок.
- Дневной лимит Cloudflare общий для всех его нейросетей. Если использовать Cloudflare ещё и для текстов, картинок в день будет меньше.
