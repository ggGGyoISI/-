# Бот для постов в Telegram-канал

Бот пишет посты **в стиле твоего канала**, сам **ищет свежую информацию в интернете** и **публикует** их в канал: сразу или по расписанию.

**Работает бесплатно:**
- поиск в интернете через DuckDuckGo, ключ не нужен;
- тексты пишет бесплатная нейросеть: Google Gemini (бесплатный тариф), Groq, OpenRouter (`:free`-модели) или локальная Ollama;
- запустить можно на своём компьютере или на бесплатном хостинге.

## Возможности

| Что | Как |
|---|---|
| Написать пост | прислать тему текстом или `/post тема` |
| Научить стилю | переслать боту 5–15 постов из канала, `/style описание`, `/addsample текст` |
| Идеи по свежим новостям | `/ideas тематика канала`, затем нажать номер идеи |
| Доработать черновик | кнопки «🔄 Другой вариант» и «✏️ Правки» |
| Опубликовать | кнопка «✅ Опубликовать» |
| Отложить | кнопка «🕒 Запланировать», потом `18:30`, `завтра 9:00`, `25.12 10:00` или `через 2 ч` |
| Очередь | `/queue` |

К каждому черновику бот присылает список источников, чтобы можно было проверить факты.

## Запуск (5 минут)

1. **Создай бота.** Напиши [@BotFather](https://t.me/BotFather), выполни `/newbot` и скопируй токен.
2. **Получи бесплатный ключ нейросети** на https://aistudio.google.com/apikey (Gemini).
3. **Узнай свой Telegram ID** у [@userinfobot](https://t.me/userinfobot).
4. **Добавь бота в администраторы канала** с правом «Публикация сообщений».
5. Установи и запусти (нужен Python 3.10+):

```bash
cd telegram_post_bot
python -m venv .venv
# Windows: .venv\Scripts\activate    Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env      # впиши BOT_TOKEN, LLM_API_KEY, ADMIN_IDS, CHANNEL
python bot.py
```

6. Открой бота в Telegram, перешли ему несколько постов из канала и пришли тему.

## Другие бесплатные нейросети

Бот работает с любым OpenAI-совместимым API, поэтому провайдера можно сменить тремя строками в `.env`:

```env
# Groq — https://console.groq.com/keys
LLM_BASE_URL=https://api.groq.com/openai/v1
LLM_MODEL=llama-3.3-70b-versatile

# OpenRouter — https://openrouter.ai/keys (выбирай модели с суффиксом :free)
LLM_BASE_URL=https://openrouter.ai/api/v1
LLM_MODEL=<модель>:free

# Ollama — полностью локально, без интернета для нейросети
LLM_BASE_URL=http://localhost:11434/v1
LLM_API_KEY=ollama
LLM_MODEL=qwen2.5:14b
```

У бесплатных тарифов есть лимиты запросов в минуту и в сутки. Если лимит исчерпан, бот попросит немного подождать. На один пост уходит 2 запроса к нейросети.

## Где запустить бесплатно, чтобы работал 24/7

- Свой компьютер или старый ноутбук: `python bot.py`.
- Бесплатная виртуальная машина, например Oracle Cloud Always Free или Google Cloud e2-micro. Запусти через `screen`/`tmux` или systemd.
- Любой хостинг, где можно запустить Python-процесс. Боту не нужен веб-сервер, он работает через long polling.

Данные (стиль, черновики, очередь) хранятся в `data/state.json`. Для отложенных постов бот должен быть запущен в момент публикации.

## Файлы

- `bot.py` — команды, кнопки, публикация и планировщик;
- `writer.py` — промпты и генерация через нейросеть;
- `search.py` — поиск DuckDuckGo и чтение страниц;
- `formatting.py` — очистка HTML под требования Telegram;
- `storage.py` — хранение в JSON;
- `config.py` — настройки из `.env`.

## Ограничения

- Telegram не даёт ботам читать историю канала, поэтому стиль задаётся пересылкой постов.
- Бот публикует только текстовые посты, без картинок.
- DuckDuckGo иногда временно ограничивает частые запросы. Тогда бот напишет пост без свежих данных, и это будет видно по отсутствию источников.
